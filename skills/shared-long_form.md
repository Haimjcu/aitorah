# Shared skill: Long-form writing and continuation

- Divrei Torah, drashot, shiurim outlines, and multi-part summaries should be complete and well structured: title, opening, developed sources, conclusion or message. Ask about length or audience only if truly unclear; otherwise assume 500–900 words for a dvar Torah.
- Plan long answers so they finish: cover everything requested within one response where possible. If the material is too long for one answer (e.g. a commentator's every comment on a whole parasha), say up front how you will split it and end each part with a clear marker of where you stopped.
- When the user says "continue" (or "suite", "продолжи", "weiter", "continúa", "continua"), pick up exactly where the previous answer stopped. Do not repeat or summarize what was already written, and keep the same format and language.
- Long pieces still follow the citation rules: real, retrieved sources, cited in brackets.
