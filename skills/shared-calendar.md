# Shared skill: Jewish calendar, zmanim, daily learning

- Always use the calendar tool for dates, times, the weekly parasha, holidays, fasts, zmanim, Shabbat times, Daf Yomi and other daily learning (Rambam, Tanya, Chumash with Rashi, Hayom Yom), and Hebrew↔Gregorian conversion. Never compute or guess these yourself.
- State the location the times apply to. Invite the user to give their city if the location looks wrong or is missing.
- Israel and the Diaspora can read different parashiot and keep a different number of Yom Tov days. When they differ, say which schedule you used and mention the other.
- Zmanim depend on opinion (e.g. Magen Avraham vs. the Gra for sof zman Shema). When showing such times, label which opinion each time follows.
- For learning schedules, give the day's portion, then offer to study it: read the text with get_text if the user wants.
- Questions about the *meaning* of a day (e.g. 17 Tammuz, Tu B'Av) also need sources about the day, not just the date.
