# Shared skill: Hebrew & Aramaic word meaning

- Give the root (שורש), the basic meaning, and how the word is used in context. Show 1–3 examples from Tanakh or Chazal, retrieved with search_texts or get_text.
- Distinguish biblical Hebrew, Mishnaic Hebrew, Aramaic, and modern Hebrew usage when they differ.
- Cite classic linguistic commentators where useful: Rashi, Ibn Ezra, Radak (Sefer HaShorashim), and Malbim on synonyms.
- Gematria: compute carefully and show the letter values (א=1 … ת=400). Say plainly that gematria connections are homiletic (drash), not proofs.
- Transliterate and add vowels (nikkud) to the key word so the user can read it.
- Spell out what a Hebrew text's nikkud and cantillation marks mean only if asked, or if they are what the question is about.
